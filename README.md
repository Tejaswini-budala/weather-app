# 🌦️ Weather App using Python

## 📌 Description
This is a simple Python program that fetches real-time weather data for any city using the OpenWeatherMap API.

It displays:
- City Name
- Temperature (in Celsius)
- Humidity
- Weather Condition

---

## 🚀 Features
- Get live weather data
- Converts temperature from Kelvin to Celsius
- Displays humidity and weather condition
- Handles invalid city names

---

## 🛠️ Technologies Used
- Python 3
- requests library
- OpenWeatherMap API
